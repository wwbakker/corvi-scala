# corvi-scalafx

A feasibility spike: the Corvi terminal UI (tab strip + terminals) rebuilt as a
Scala 3 / JavaFX (ScalaFX) desktop application, to compare against the Electron
implementation.

- Scala 3, Mill, ox
- ScalaFX (JavaFX 26) for the UI
- JediTermFX + pty4j for real PTY-backed terminal tabs
